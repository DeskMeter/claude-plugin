---
description: Stop Desk Meter using your status line (restores any previous one)
---

Undo Desk Meter's status line change.

Run `"${CLAUDE_PLUGIN_ROOT}/scripts/desk-meter" remove-statusline` with the Bash tool and tell the user in one line what it did. Mention that their list of meters is kept in `~/.config/desk-meter/` in case they set it up again, and that they can remove the plugin itself with `/plugin`.
